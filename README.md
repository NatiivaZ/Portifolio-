# Portfólio Pessoal

Site de portfólio profissional em Next.js — para uso e edição local.

## Início rápido

```bash
npm install
npm run dev
```

Abra: **http://localhost:3002**

## Onde editar o conteúdo

| Arquivo | O que alterar |
|---------|---------------|
| `data/site-content.ts` | Nome, textos, redes sociais, experiências |
| `data/projects.json` | Projetos do portfólio |
| `public/images/` | Fotos e imagens |

## Comandos

- `npm run dev` — servidor de desenvolvimento (porta 3002)
- `npm run build` — build de produção
- `npm run start` — rodar build local

## Tecnologias

- Next.js 14
- TypeScript
- Tailwind CSS
- shadcn/ui
